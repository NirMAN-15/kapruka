# Kapruka Agent Challenge 2026 - Challenge Brief

This document compiles all details, rules, deadlines, and criteria for the **Kapruka Agent Challenge 2026**.

---

## 🏆 The Challenge Mission
Turn the **Kapruka Model Context Protocol (MCP) Server** into a **beautiful, full-screen chat shopping experience** that real customers would love to use. The application must connect to live products, live delivery quotes, and guest checkout to allow a complete, immersive, end-to-end commerce experience.

---

## 📅 Key Timeline & Dates
*   **Registration & Build Period:** Open Now
*   **Submission Deadline:** **30 June 2026 (End of Day)**
*   **Judging Period:** July 2026

## 📊 Scoring Rubric (Out of 100)

Your submission will be evaluated by the Kapruka tech team using the following detailed criteria:

| Category | Weight | Description |
| :--- | :---: | :--- |
| **Experience & Polish** | **30** | Does the interface look and feel genuinely amazing? High-quality UI, smooth animations, zero friction. |
| **Visual Richness** | **20** | Products shown beautifully. Rich cards, image carousels, clean details—avoiding walls of plain text. |
| **Personality** | **15** | An agent that users actually enjoy speaking to. Helpful, witty, warm, or custom-tailored voice. |
| **Usefulness** | **15** | Does it genuinely help customers discover the right gifts/products and confidently navigate choices? |
| **End-to-End Completeness** | **15** | Guides the user all the way from search/discovery, delivery validation, to a working checkout page. |
| **Creativity** | **5** | Surprise elements, innovative UX features, or clever shopping assistance hooks. |
| **Total** | **100** | |

## ⭐ Bonus Points (High Priority)
Nailing these optional constraints will separate standard submissions from the winning one:
1.  **Sinhala-Language Support (🇱🇰):** Build native Sinhala chat capabilities. Fits the local market perfectly and is highly valued by judges.
2.  **Tanglish Conversation:** Seamlessly support bilingual dialogue (Sinhala words written in English letters / Sinhala-English code-switching).
3.  **Multi-Item Carts:** Allow users to add multiple different products to a shopping cart and check out in a single order.
4.  **Delivery-Date Constraints:** Intelligently query delivery timelines (especially for cakes/flowers) and handle constraints.
5.  **Gift Messaging:** Collect sender/recipient names and let users add custom greeting card text for gift orders.

---

## ⚖️ Rules & Eligibility
*   **Location:** Open only to Sri Lankans currently based in Sri Lanka (no diaspora submissions).
*   **Team Size:** Solo builders only. One entry per person, one prize.
*   **Hosting:** The application must be deployed on a live, public, reliable URL that judges can open in a browser and test immediately.
*   **Tool Usage:** Must be built using the official **Kapruka MCP**. Any choice of LLM, frontend framework, or hosting provider is allowed.
*   **Integrity:** Respect customers, the catalog, and checkout APIs. **No spamming or abuse** of live checkout/order tools.
